# Data

This project uses the Netflix Movies and TV Shows dataset.

The original dataset is not currently included in this repository. The analysis was conducted on a dataset containing 8,807 Netflix titles, including movies and TV shows added between 2008 and 2021.

Key fields used in the analysis include:

- `type`
- `title`
- `date_added`
- `release_year`
- `listed_in`
- `country`

The `listed_in` field contains multiple genre labels per title and was transformed into separate genre-level records for analysis.
